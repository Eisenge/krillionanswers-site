Krillion: So spielt man — der Daily Dive erklärt

Krillion (The Daily Dive) gibt dir sieben Prompts und etwa 25 Sekunden pro Prompt, um eine Antwort zu tippen. Seltene Antworten bringen deutlich mehr Punkte als offensichtliche. So läuft eine Runde ab – vom ersten Prompt bis zu deiner finalen Tiefe.

Was passiert in einer Runde

Öffne krillion.io und starte den Daily Dive. Du bekommst sieben Prompts nacheinander. Jeder Prompt ist eine Kategorie oder offene Frage, zum Beispiel ein Land, das mit O endet, ein Meer, ein Singvogel, ein chinesisches Gericht. Du hast etwa 25 Sekunden pro Prompt, um eine Antwort zu tippen und zu bestätigen.

Warum seltene Antworten zählen

Das Spiel vergleicht deine Antwort mit dem, was andere Spieler an diesem Tag tippen. Häufige Antworten bewegen deinen Score kaum. Ungewöhnliche, konkrete Antworten lassen dich tiefer sinken. Krillion nutzt dafür eine Tauch-Metapher: Je seltener deine Antworten, desto tiefer tauchst du; offensichtliche halten dich nahe der Oberfläche.

Der Tiefen-Score

  • Seltene Antworten lassen dich tiefer sinken — die Tiefe ist dein Tagesergebnis.
  • Offensichtliche Antworten zählen kaum — eine häufige Wahl hält dich nahe der Oberfläche.
  • Für alle dieselben Prompts — alle Spieler beantworten dieselben sieben Prompts, daher sind Tagesergebnisse vergleichbar.
  • Ein Daily Dive pro Tag — die tägliche Runde setzt sich täglich zurück; Archiv- und Unbegrenzt-Modus lassen dich mehr spielen.

So gibst du eine Antwort ein

  • Lies den Prompt — entscheide, was gefragt ist (ein Land, ein Lied, ein Gericht).
  • Wähle eine konkrete, gültige Antwort — präzise Namen schlagen breite Kategorien.
  • Tippe und bestätige schnell — der Timer liegt bei etwa 25 Sekunden, also bleib bei deiner ersten guten Idee.
  • Kein Konto nötig — das Tages-Spiel läuft kostenlos im Browser.

Häufige Fehler neuer Spieler

  • Eine breite Kategorie tippen — ein allgemeines Wort bringt viel weniger als ein konkreter Name.
  • Sich selbst anzweifeln — bei 25 Sekunden ist die erste gültige seltene Idee oft die beste.
  • Den Prompt nicht prüfen — eine Nachbarkategorie (eine Region statt eines Landes) bewertet meist schlechter.
  • Denken, man brauche eine App — Krillion ist ein Browserspiel; nichts muss installiert werden.

Modi jenseits der Tagesrunde

Auf krillion.io gibt es auch ein Archiv vergangener Dives, Themen-Pakete und einen Unbegrenzt-Modus. Wenn du außerhalb der Tagesrunde üben willst, sieh dir unsere Krillion-Unlimited-Anleitung an.

Ist das die offizielle Krillion-Seite?

Nein. Das ist eine unabhängige Anleitung. Das offizielle Spiel ist krillion.io; wir erklären nur, wie es funktioniert und wie man besser spielt.
